
# Desafio QA - Cucumber e Gherkin

## Objetivo
Desenvolver cenários de teste utilizando BDD (Behavior Driven Development) com Cucumber/Gherkin para validar a funcionalidade de login do Portal EBAC.

---

## Funcionalidade testada
Tela de Login do Portal EBAC.

---

## Cenários desenvolvidos
- Autenticação válida
- Usuário inexistente
- Usuário com senha inválida
- Esquema do cenário para múltiplos usuários

---

## Tecnologias utilizadas
- Cucumber
- Gherkin
- Visual Studio Code

---

## Aprendizados
Durante este desafio aprendi:

- Estruturar cenários em Gherkin
- Utilizar Contexto (Background)
- Criar Scenario Outline (Esquema do Cenário)
- Trabalhar com Examples
- Configurar o idioma português com `# language: pt`
- Resolver problemas de configuração da extensão Cucumber no VS Code

---

## Troubleshooting realizado
Durante o desenvolvimento ocorreu erro de formatação no VS Code:

Request textDocument/formatting failed

Solução aplicada:
- desinstalação da extensão Cucumber (Gherkin) Full Support
- reinstalação da extensão
- reinicialização do VS Code

Resultado: ambiente funcionando corretamente.
